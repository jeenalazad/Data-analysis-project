# Netflix Data Analysis Project

## Overview
This project explores Netflix data using Python to understand content distribution, trends, and other insights about movies and TV shows.

## Objectives
- Explore and understand the Netflix dataset.
- Clean and preprocess data.
- Analyze movies and TV shows.
- Visualize patterns and trends in the data.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- CSV datasets

## Project Files
- `Dataset.csv` — Original dataset
- `Netflix_Cleaned.csv` — Cleaned dataset
- `NetflixDataset_Analysis-2.ipynb` — Jupyter Notebook containing the analysis
- `netflixdataset_analysis-2.py` — Python analysis script
- `Screenshots.pdf` — Project screenshots
- `Task1_report.pdf` — Task 1 report
- `Task2_report.pdf` — Task 2 report
- `Task4,5_report.pdf` — Task 4 and 5 report

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries using `pip install pandas matplotlib`.
3. Open `NetflixDataset_Analysis-2.ipynb` in Jupyter Notebook.
4. Run the notebook cells to explore the analysis.

## Learning Outcomes
- Data cleaning and preprocessing
- Exploratory data analysis
- Data visualization
- Working with datasets using Python and Pandas
